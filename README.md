# 和平精英 · 四域 × 八状态灵敏度计算器

**在线使用：<https://poisongod.github.io/fov-calculator/>**

以红点 / 全息 / 机瞄为绝对基准，把开镜、开镜开火、陀螺仪、陀螺仪开火四个域统一到同一套 `k = tan(FOV状态/2) / tan(FOV红点/2)` 系数。

- 4 域 × 8 状态 = 32 个灵敏度槽
- 游戏内视野用 `%`（80 / 90 / 103），几何量用水平 FOV `°`
- 镜头域上限 300%，陀螺仪域上限 600%
- 纯静态单文件，无外部依赖，可离线打开 `index.html`
- 支持复制结果、重置、陀螺仪口径切换

## 本地打开

直接双击 `index.html`，或：

```bash
python3 -m http.server 8080
```

## 说明

本工具是几何 / 灵敏度换算，不修改游戏文件。不同版本、机型、后坐力与陀螺仪噪声需自行微调。
