READ

高倍镜数值低不是“变钝”，而是抵消倍镜放大后的视觉加速；TPP / FPP 的 k > 100% 因为不开镜的有效灵敏度视野比红点更宽。屏幕等距下四个域共用同一组 k，只改红点基准 B；角度 1:1 时陀螺仪两域改用 1（取基准值），镜头两域仍用 k；上限只截断结果，不改变 k。
TPP / FPP 的 k 按有效灵敏度 FOV（默认 75°）计算，不是画面视觉 FOV；k 列 146.77% 即无量纲系数 1.4677；镜头 300% 上限可能先截断 TPP / FPP。

MODEL

核心公式

%
S = clamp( round( B × k ), 0, cap ) // 单位：%
倍镜：k = tan(FOV状态 / 2) / tan(FOV红点 / 2) = 1 / m
TPP/FPP：k = tan(F_sens / 2) / tan(FOV红点 / 2)
s ∈ { TPP, FPP, 1X, 2X, 3X, 4X, 6X, 8X }
cap = 300（开镜 / 开镜开火）或 600（陀螺仪 / 陀螺仪开火）

四个域 × 八个状态共用同一组 k；开火域如果要更稳，只能整体乘一个常数，例如 B_adsf = 1.1 × B_ads，不能给单个状态加数值。TPP / FPP 的 k 可以大于 1，但这里用的是有效灵敏度 FOV（约 75°），不是画面上的视觉 FOV（80%/90%/103%）。游戏统一控制在红点 68/69 时把 TPP/FPP 自动填成 100%，反推正是约 75–77°；如果继续用视觉 FOV 计算，TPP/FPP 会被高估到 161%/191%。

BOUNDARY

必须知道的边界

  • 01

    后坐力不是灵敏度。灵敏度只统一“你动多少 → 镜头转多少”；枪口自己跳多少是加性扰动，模型不能抵消。

  • 02

    TPP/倍镜 80/90 各含 7 张实机图。每组都是第三人称 + 红点 + 2X–8X；同一倍镜在两组里的红靶像素差 <0.3%，变化的只有第三人称视野。FPP 另有 80/90/103 三张，红心尺寸按 tan 律变化。

  • 03

    红点不是 45°。不开镜是第三人称，相机在角色后方；去掉相机后移后，红点相对腰射约 1.6×，对应 55.2°。

  • 04

    上限不同，系数相同。镜头 300% / 陀螺仪 600% 只是 B 的取值范围，不是两套 k；600% 不代表系数翻倍。

  • 05

    TPP / FPP 用的是灵敏度 FOV，不是视觉 FOV。画面视野 80%/90%/103% 只决定你看到多宽；游戏统一控制反推的灵敏度 FOV 约 75–77°，所以 TPP/FPP 的 k 约 1.47，而不是 1.61/1.91。换视觉 FOV 后建议用左上角“从游戏值反推”重新标定。
